# Netmon - Улучшенная версия

Сетевой монитор с исправленными ошибками и улучшенной функциональностью.

## Основные улучшения

### ✅ Исправленные проблемы:
1. **Дублирование устройств в API** - добавлена проверка уникальности IP-адресов
2. **Синтаксические ошибки в network_data.py** - исправлена структура CONNECTIONS
3. **Проблемы с кодировкой** - исправлен вывод кириллицы в CLI-сканере
4. **Неполные зависимости** - обновлен requirements.txt
5. **Отсутствие логирования** - добавлено подробное логирование

### ✅ Новая функциональность:
1. **Автоматическое сканирование** - фоновая задача сканирует сеть каждые 5 минут
2. **Улучшенная обработка ошибок** - graceful degradation при проблемах с сетью
3. **Health-check эндпоинты** - `/api/health` и `/api/config`
4. **Управление сканированием** - ручной запуск через API (`POST /api/network/scan`)
5. **Логирование в файл** - все операции логируются в `app/netmon.log`

### ✅ Безопасность и надежность:
1. **Валидация данных** - проверка корректности IP и MAC-адресов
2. **Блокировки потоков** - thread-safe доступ к общим данным
3. **Грамотная остановка** - корректная остановка фоновых задач
4. **Конфигурация через .env** - все настройки в одном файле

## Быстрый старт

### Установка:
```bash
# Клонирование проекта (если еще не сделано)
git clone <ваш-репозиторий>
cd netmon

# Установка зависимостей
pip install -r requirements.txt
```

### Запуск улучшенной версии:
```bash
# Способ 1: Через скрипт запуска
python run_improved.py --improved

# Способ 2: Напрямую
python app/app_improved.py

# Способ 3: Запуск тестов
python run_improved.py --test
```

### Запуск оригинальной версии:
```bash
python run_improved.py --original
# или
python app/app.py
```

## Конфигурация

Создайте файл `.env` в корне проекта (автоматически создается при первом запуске):

```env
# Конфигурация сетевого монитора
RADMON_HOST=192.168.1.103
RADMON_PORT=5000
SUBNET=192.168.1.0/24
SCAN_INTERVAL=300      # Интервал сканирования в секундах
MAX_WORKERS=128        # Количество потоков для параллельного сканирования
PING_TIMEOUT=2         # Таймаут ping в секундах
LOG_LEVEL=INFO         # Уровень логирования (DEBUG, INFO, WARNING, ERROR)

## API эндпоинты

### Основные:
- `GET /` или `GET /network` - Веб-интерфейс карты сети
- `GET /api/network/info` - Текущее состояние сети
- `GET|POST /api/network/scan` - Сканирование сети
- `GET /api/network/topology` - Топология сети
- `GET /api/device/<ip>` - Информация об устройстве
- `GET /api/device/<ip>/services` - Сервисы устройства

### Новые:
- `GET /api/health` - Проверка здоровья приложения
- `GET /api/config` - Текущая конфигурация
- `PUT /api/device/<ip>` - Изменение статуса устройства

## Фоновое сканирование

Приложение автоматически сканирует сеть с заданным интервалом:
- По умолчанию: каждые 5 минут (300 секунд)
- Можно изменить через переменную `SCAN_INTERVAL` в `.env`
- Результаты обновляются в реальном времени

### Ручное управление сканированием:
```bash
# Запуск сканирования через API
curl -X POST http://192.168.1.103:5000/api/network/scan

# Или с параметром force
curl http://192.168.1.103:5000/api/network/scan?force=true
```

## Логирование

Логи сохраняются в файл `app/netmon.log`:
```bash
# Просмотр логов в реальном времени
tail -f app/netmon.log

# Поиск ошибок
grep ERROR app/netmon.log

# Просмотр последних 100 строк
tail -100 app/netmon.log
```

Уровень логирования настраивается через переменную `LOG_LEVEL`:
- `DEBUG` - максимальная детализация
- `INFO` - стандартный уровень (по умолчанию)
- `WARNING` - только предупреждения и ошибки
- `ERROR` - только ошибки
