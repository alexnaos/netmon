# Скрипты миграции Home Assistant (.103 → .91)

Порядок выполнения (запускать вручную по SSH на соответствующих машинах):

| № | Скрипт | Где запускать | Что делает |
|---|--------|---------------|------------|
| 1 | `backup_remove_ha_91.sh` | **на .91** | Бэкапирует и удаляет существующий HA на 91 |
| 2 | `copy_config_103_to_91.sh` | **на .103** | Копирует конфигурацию с 103 на 91 (rsync, без runtime) |
| 3 | `install_ha_91.sh` | **на .91** | Устанавливает HA через Docker на 91 |
| 4 | `fix_config_91.sh` | **на .91** | Правляет `configuration.yaml` под 91 (MQTT на .23, ссылки .103→.91) |
| — | `migrate_ha_103_to_91.sh` | — | Главный сценарий с последовательностью шагов |

## Требуется

- SSH-доступ по ключам: `alex@192.168.1.103` и `alex@192.168.1.91`
- На .91: Docker (для запуска HA контейнера)
- На .103: запущенный HA с конфигом в `/home/alex/hass_config/`

## Быстрый старт

```bash
# Скопировать скрипты на серверы
scp scripts/*.sh alex@192.168.1.103:/home/alex/
scp scripts/*.sh alex@192.168.1.91:/home/alex/

# На .103: дать права
ssh alex@192.168.1.103 'chmod +x /home/alex/*.sh'

# На .91: дать права
ssh alex@192.168.1.91 'chmod +x /home/alex/*.sh'

# Выполнять по порядку шаги из migrate_ha_103_to_91.sh
```

## Важные особенности конфигурации .91

- **Нет локального mosquitto** — MQTT broker указывается на `192.168.1.23:1883` (или `.103:1883`)
- **Разные init-системы** — на .91 SysV init, нет `systemctl`, Docker управляется вручную
- **Wi-Fi только** — на .91 работает только `wlan0` (.91), `eth0` DOWN
- **Не копировать runtime** — `.storage/`, `.cache/`, `*.db`, `*.log`, `.uuid` исключаются из копирования
