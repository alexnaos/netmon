## 🔧 РЕШЕНИЕ ПРОБЛЕМ

### Частые проблемы и решения:
1. **Порт 5000 занят**: `netstat -ano | findstr :5000` → `taskkill /PID <номер> /F`
2. **Python не найден**: Проверьте PATH или используйте полный путь
3. **Зависимости не установлены**: `pip install -r requirements.txt`
4. **Приложение не запускается**: Запустите `setup_and_run.bat`

## 🚚 ПЕРЕНОС НА ДРУГУЮ МАШИНУ

### Подготовка к переносу:
1. Скопируйте всю папку `netmon`
2. Измените `RADMON_HOST` в `.env` на IP новой машины
3. Запустите `setup_and_run.bat`

### Быстрый перенос:
```bash
# На новой машине
cd C:\Projects\PlatformIO
xcopy \\192.168.1.103\Projects\PlatformIO\netmon netmon /E /I
cd netmon
edit .env  # Измените RADMON_HOST
setup_and_run.bat
```
