# РУКОВОДСТВО ПО ЛОКАЛЬНОМУ ТЕСТИРОВАНИЮ

## 🎯 ЦЕЛЬ
Проверить работу Netmon на локальной машине перед переносом на другую машину.

## 📋 КАК ИСПОЛЬЗОВАТЬ

### Вариант 1: Быстрый запуск (рекомендуется)
```bash
# Самый простой способ
test_local.bat
```
**Результат:** Откроет браузер с http://127.0.0.1:5000/network

### Вариант 2: Выбор адреса запуска
```bash
# Позволяет выбрать адрес
start_local_test.bat
```
**Выбор:**
- `1` - 127.0.0.1 (только локально)
- `2` - 0.0.0.0 (все интерфейсы)  
- `3` - 192.168.1.103 (оригинальный)

### Вариант 3: Скрипт управления конфигурациями
```bash
# Показать текущую конфигурацию
python switch_config.py show

# Переключить на локальную (127.0.0.1)
python switch_config.py local

# Переключить на все интерфейсы (0.0.0.0)
python switch_config.py all

# Переключить на оригинальную (192.168.1.103)
python switch_config.py original

# Восстановить из резервной копии
python switch_config.py restore
```

## 🔧 КОНФИГУРАЦИОННЫЕ ФАЙЛЫ

### Основные файлы:
- `.env` - Текущая активная конфигурация
- `.env.original` - Резервная копия оригинальной конфигурации
- `.env.local` - Шаблон для локальной конфигурации
- `.env.test` - Временная конфигурация для тестов

### Содержимое конфигурации:
```env
RADMON_HOST=127.0.0.1       # Адрес запуска
RADMON_PORT=5000            # Порт приложения
SUBNET=192.168.1.0/24      # Мониторируемая подсеть
SCAN_INTERVAL=300           # Интервал сканирования (секунды)
MAX_WORKERS=64             # Количество потоков
PING_TIMEOUT=2             # Таймаут ping
LOG_LEVEL=DEBUG            # Уровень логирования
```

**Решение:**
```bash

taskkill /F /PID <PID>
```

**Решение:**

```bash
python app\app.py
```

## 🎉 ЧТО ДАЛЬШЕ?

### Если всё работает:
1. Измените `RADMON_HOST` в `.env` на IP новой машины
2. Скопируйте всю папку на новую машину
3. Запустите `setup_and_run.bat`

### Если есть проблемы:
1. Проверьте логи в `app\netmon.log`
2. Убедитесь, что порт 5000 свободен
3. Проверьте Python и зависимости
